# 事件驱动 USD/CNY v2：境内定价变量的预注册规则

v1 规则见 [`event-driven-plan.md`](event-driven-plan.md)，结论见 [`event-driven-results.md`](event-driven-results.md)（负结果）。
本文件在**看到任何 v2 收益结果之前**写完并提交。

## 0. v2 为什么值得跑

v1 全程只有**美国侧**变量（`Δ2Y` / `ΔDXY` / `VIX`）。USD/CNY 是被管理的汇率，它的定价有一半在境内：中间价、离岸压力、结售汇。v1 等于只看了半张牌就下了结论。

`data/market/CNY_FIXING.csv`（CFETS 官方中间价）和 `data/market/USDCNH.csv`（离岸人民币）已经补齐，v2 补的就是这半张牌。

## 1. 这是这批样本外上的**第二次也是最后一次**检验

v1 已经用掉了一次 2025-01 ~ 2026-08 的样本外。v2 再用一次，就是在同一批数据上做第二次检验，必须付出代价：

- **主判据显著性门槛由 `p <= 0.05` 收紧到 `p <= 0.025`**（两次检验的 Bonferroni 校正）。
- **本窗口不允许有 v3。** v2 跑完，2025-01 ~ 2026-08 这段样本外就用尽了。之后任何新想法只能向前纸面跟踪，等新数据积累。

这条先写在最前面，是因为它是最容易被违反的：负结果之后总会想"再换一组变量试试"，而试到第三次，样本外就已经变成训练集了。

## 2. 新变量（冻结）

| 变量 | 定义 | 何时可知（北京时间） |
| --- | --- | --- |
| `FIX_SURP[D]` | `ln(FIX[D]/FIX[D-1]) - ln(SPOT[D-1]/SPOT[D-2])` | **D 日 09:15**，中间价公布时 |
| `dCNH[D]` | `ln(CNH[D]/CNH[D-1])` | D 日约 23:30，离岸收盘 |
| `CNH_PREM[D]` | `ln(CNH[D]/SPOT[D])` | 同上（含口径错配，见下） |

`FIX` = CFETS 人民币兑美元中间价，`SPOT` = `DEXCHUS`（FRED，纽约中午买入价），`CNH` = 东财美元兑离岸人民币收盘。

### 为什么 `FIX_SURP` 要做差分

直接用 `ln(FIX[D]/SPOT[D-1])` 不行：即期对中间价存在**持续的水平偏离**（v1 实测平均 +0.2866%），这个量级远大于日度新息，会把"意外"淹没成一个慢变的水平项。实测印证：未差分版本的中位数 0.141% 而 85 分位 1.148%，是被水平项主导的重尾分布。

差分掉前一日的即期变动之后，分布正常（中位数 0.109%、85 分位 0.287%），量的才是**中间价相对市场自身走势的偏离**，也就是逆周期调节的方向。

### 口径缺陷（必须标注）

`CNH` 是东方财富转手数据，非权威源，收盘时点与 `DEXCHUS` 的纽约中午价相差约半天。因此 `CNH_PREM` 带有时点错配，只作辅助描述，**不进主判据的方向规则**。`dCNH` 分子分母同源同时点，无此问题，可以进。

## 3. 意外阈值（冻结）

阈值取自**训练期（2019-06-28 ~ 2024-12-31）解释变量自身的分位数**，四舍五入取整。计算过程只用解释变量，未触碰任何收益序列。

| 档 | 条件 | 对应训练期分位 |
| --- | --- | --- |
| 主档 | `\|FIX_SURP\| >= 0.10%` 或 `\|dCNH\| >= 0.17%` | 约上 50% |
| 严档 | `\|FIX_SURP\| >= 0.30%` 或 `\|dCNH\| >= 0.42%` | 约上 15% |

分位数取自训练期，与 v1 两档的通过比例大致对齐，便于横向比较。两档都必须报告。

## 4. 方向规则（冻结）—— 与 v1 的关键结构差异

**v1 的教训：类目其实没有进入方向。** v1 的规则表用新闻类目决定"用哪一行"，但每一行的输入都是市场变量，所以新闻实际上只起了筛选作用。这让增量检验变得绕。

v2 直接把这件事摆平：

> **方向完全由境内变量给出，新闻类目只作为"这天算不算事件"的筛选器。**

这样增量检验就是一句话：**同一套方向规则，加了新闻条件之后，是不是比不加更准。**

### 规则表

| 条件 | USD/CNY 方向 |
| --- | --- |
| `FIX_SURP > 0` 且 `dCNH > 0` | 上行（中间价容忍贬值 + 离岸走弱，共振） |
| `FIX_SURP < 0` 且 `dCNH < 0` | 下行（逆周期收紧 + 离岸走强，共振） |
| 两者符号冲突 | **无方向，不进统计** |

方向含义：`FIX_SURP > 0` 表示中间价被定得比市场自身走势更弱，读作政策容忍贬值；`< 0` 表示定得更强，读作逆周期抵抗。`dCNH > 0` 表示离岸人民币走弱。

规则只有三行，没有自由裁量项，没有备选参数。

## 5. 窗口（冻结）

| 窗口 | 定义 | 角色 | 决策时点 |
| --- | --- | --- | --- |
| `r1` | `ln(SPOT[D+1]/SPOT[D])` | **主判据**（与 v1 可比） | D 日境内收盘后 |
| `rF` | `ln(SPOT[D]/FIX[D])` | **新窗口**：中间价公布 → 当日纽约中午 | **D 日 09:15**，中间价公布后 |
| `r5` | `ln(SPOT[D+5]/SPOT[D])` | 持续性，描述性 | D 日收盘后 |

### `rF` 是 v1 做不到的新东西

中间价在北京时间 09:15 公布，境内即期 09:30 开盘。也就是说**每天早上有一个明确的政策信号先落地，然后市场才开始交易**。`rF` 度量的正是这段"信号已知、行情未走"的区间——这是整个项目里唯一一个信号明确领先于窗口的设置。

### `rF` 的硬约束：规则输入必须排除 `FIX[D]`

因为恒等式：

```
rF + FIX_SURP_undiff = r0        其中 FIX_SURP_undiff = ln(FIX[D]/SPOT[D-1])
```

`FIX[D]` 同时出现在 `rF` 的分母和 `FIX_SURP` 里，任何用 `FIX_SURP` 符号去预测 `rF` 符号的规则都带**机械负相关**，得出的高命中率是恒等式的产物，不是发现。

**因此 `rF` 窗口只用一条规则：`dCNH[D-1] > 0 → 上行，< 0 → 下行`**（`CNH[D-1]` 在北京时间 D-1 日 23:30 收盘，早于 D 日 09:15 的中间价，无前视）。

这条约束和 v1 第 5 节"意外和响应不允许同段测量"是同一个东西的第二次应用。v1 靠它挡掉了一个 78.6% 的假发现，这次提前挡在设计里。

## 6. 对照与基线（冻结）

| 检验 | 做法 |
| --- | --- |
| 主检验 | 事件条件下的有向命中率 vs 50%，单侧精确二项检验 |
| 安慰剂 | 事件日之间随机重排方向标签 1000 次，种子 `20260830` |
| **增量检验** | 同一套方向规则在**全部报价日**上跑（去掉新闻条件），比较命中率 |

v2 的增量检验比 v1 干净得多：因为方向规则本身不含新闻，"有新闻条件"和"无新闻条件"是同一个规则的两个样本，差异可以直接归因于新闻筛选。

`B3` = 主档方向规则在全报价日；`B4` = 严档方向规则在全报价日。

## 7. 验收标准（冻结）

### 方向目标（`r1` 主判据）

1. 样本外有效事件数 `n >= 30`
2. 样本外命中率单侧二项检验 **`p <= 0.025`**（第 1 节的两次检验校正）
3. 样本外命中率 >= 训练期命中率 − 5 个百分点
4. 安慰剂中重排跑赢真实信号的比例 `<= 10%`
5. 增量检验：事件条件命中率显著高于全报价日基线（`p <= 0.10`）

五条全过才算"新闻在境内变量之上有增量信息"。

### `rF` 目标（独立结算）

`rF` 回答的是另一个问题：**离岸隔夜走势对"中间价公布后到当日纽约中午"这段有没有方向信息。** 它与新闻无关，验收标准：

1. `n >= 100`
2. 样本外 `p <= 0.025`
3. 样本外相对训练期不衰减超过 5 个百分点

`rF` 通过而 `r1` 不通过是完全可能的结果，且**这个结果本身有实用价值**——它对应的是"每天早上看着中间价决定今天什么时候结汇"，正是即期结汇择时的决策时点。

### 境内变量本身（附带回答，不设验收）

`B3`/`B4` 基线的命中率就是"境内变量本身有没有方向信息"的答案。这是 v1 从未问过的问题，无论新闻有没有增量，这个数字都要报告。

## 8. 终止条件

- 任一验收不过 → 登记负结果，不调参、不重跑、不换阈值。
- **无论 v2 结果如何，2025-01 ~ 2026-08 这段样本外就此用尽。** 没有 v3。
