# v2 结果：境内定价变量的检验与登记

规则见 [`event-driven-plan-v2.md`](event-driven-plan-v2.md)，冻结于 commit `ecee710`，早于本文件。
原始数字见 `data/events/study_report_v2.json`。**样本外只跑了一次，且这是该窗口上的最后一次检验。**

## 结论

> **新闻增量：第二次确认不通过。**
> **`rF` 窗口：按预注册字面通过，但预注册的零假设选错了，判定为假通过，不认。**
> 2025-01 ~ 2026-08 样本外就此用尽，没有 v3。

## 一、新闻增量（`r1` 主判据）：第二次确认失败

| 验收条件 | 门槛 | 主档实测 | |
| --- | --- | --- | --- |
| 样本外事件数 | n ≥ 30 | 110 | ✅ |
| 二项检验 | p ≤ 0.025 | **p = 0.1955**（54.55%） | ❌ |
| 不衰减 | ≥ 训练 − 5pp | 训练 54.55% → 样本外 54.55% | ✅ |
| 安慰剂 | ≤ 10% | **18.2%** | ❌ |
| 增量检验 | p ≤ 0.10 | **p = 0.5094** | ❌ |

严档样本外 n=23，未达 30，直接不成立。

**基线 `B3`（同一套方向规则，去掉新闻条件）样本外 54.70%，比加了新闻条件的 54.55% 还高一点。** 换了一整套境内变量之后，新闻的增量依然是零——而且这次的对比比 v1 干净得多，因为 v2 的方向规则完全不含新闻，"加新闻筛选"和"不加"是同一个规则的两个样本。

**境内变量本身**（`B3` 训练期 54.73%、p=0.0244；样本外 54.70%、p=0.1776）：训练期勉强显著，样本外掉出显著。和 v1 的 `B1` 是同一个形状——**训练期像有东西，样本外就没了**。

## 二、`rF` 窗口：一次教科书级的假通过

### 先看预注册怎么说

| 预注册条件 | 门槛 | 实测 | |
| --- | --- | --- | --- |
| 样本量 | n ≥ 100 | **382** | ✅ |
| 样本外显著性 | p ≤ 0.025 | **p = 0.0033**（57.07%） | ✅ |
| 不衰减 | ≥ 训练 − 5pp | 训练 55.69% → 样本外 **57.07%**（反而更好） | ✅ |

**三条全过。** 按第 7 节的字面规定，这里应该宣布"`rF` 目标通过"。

### 但零假设选错了

`rF` 不是一个对称的靶子。它有很强的无条件正漂移：

| | 训练期 | 样本外 |
| --- | --- | --- |
| `rF` 无条件均值 | **+33.12 bp** | **+17.58 bp** |
| `rF` 为正的天数占比 | **61.9%** | **53.1%** |

也就是说，**一个什么都不看、每天都喊"上行"的策略，训练期能拿 61.9%、样本外能拿 53.1%**。用 50% 当零假设去检验一个正号占比 61.9% 的靶子，检验的是漂移，不是信号。

把基准换成"永远看多"之后：

| | 规则命中率 | 永远看多 | 规则的增量 |
| --- | --- | --- | --- |
| 训练期 | 55.60% | **61.9%** | **−6.26 pp** |
| 样本外 | 57.07% | 53.1% | **+3.93 pp** |

**训练期输给平凡基准 6.26 个百分点，样本外赢 3.93 个百分点——符号都不一致。** 这不是"有增量但不稳定"，这是"没有可复现的增量"。

拆开看多空两侧，更清楚：

| | 看多天数 / 命中 | 看空天数 / 命中 |
| --- | --- | --- |
| 训练期 | 642 / **67.4%** | 635 / **43.6%** |
| 样本外 | 175 / 61.1% | 207 / 53.6% |

训练期的看空call命中率只有 43.6%，远低于随机——因为那段时间人民币持续承压，`rF` 一路正偏，凡是喊"下行"的基本都错。规则看起来的那点"信息"，主要来自它在正偏期恰好多喊了几次"上行"。

### 标签重排安慰剂说什么

补跑（**注意：这条不在预注册里，是事后加的稳健性检查**）：训练期重排跑赢比例 0.0%、样本外 0.6%。也就是相对**随机配对**，规则确实携带信息。

两个检验不矛盾，它们回答的是不同问题：

- 相对随机配对：规则有信息（两期一致）。
- 相对"永远看多"这个平凡基准：训练期是负的，样本外是正的（两期矛盾）。

**实用结论取后者。** 一个跑不赢"每天都喊涨"的规则，没有部署价值。

### 还有一个更硬的问题：中间价不可成交

即使统计上成立，`rF = ln(SPOT[D]/FIX[D])` 的起点是**人民币中间价**——它是央行公布的参考价，**不是可以成交的价格**。任何人都无法在中间价上建仓。

预注册第 5 节把 `rF` 描述成"全项目唯一信号明确领先于窗口的设置"，这句话对了一半：**信号时点确实干净（`dCNH[D-1]` 在北京 D-1 日 23:30 已知，早于 D 日 09:15 的中间价），但入场价格不可成交。** 这是 v2 预注册的第二个缺陷，和零假设选错是两件独立的事。

要把它变成可验证的东西，需要**境内即期的开盘价或日内序列**（在 09:30 开盘价入场，而不是在中间价入场）。这个数据我们没有。

### 为什么还是决定否决

预注册第 8 节写着"任一验收不过 → 登记负结果"。这里的情况反过来：**验收全过，但验收本身写错了。**

规则不允许看到结果之后放宽标准；但**收紧标准、否决一个对自己有利的结果，不属于同一类问题**。放宽是为了让结论好看，收紧是为了不骗自己。两者不对称，这一条现在补进纪律：

> 预注册的零假设写错时，以正确的零假设为准，**且只允许朝更严的方向修正**。

如果这里宣布"`rF` 通过、样本外 57.07%、p=0.0033"，它会是一个每一位数字都真实、每一句表述都符合预注册、而结论完全错误的报告。这正是整个项目要防的东西——只不过这次它是从正面来的。

## 三、一个真实的结构性发现（不是信号）

`rF` 的无条件正漂移本身值得记下来：**即期汇率系统性地比当日中间价弱**，训练期平均 33 个基点、样本外 18 个基点。

这是逆周期因子的脚印：中间价被定得比市场自发水平更强，市场随后在日内把价格推回去。它描述的是人民币定价机制的一个稳定特征，**不是可交易机会**（因为中间价不可成交）。

对企业的意义是认知性的：**"今天中间价定得比昨天强"不等于"人民币今天会强"**，多数时候只意味着当日的市场价会在更弱的位置成交。把中间价当行情指引来读，方向本身就容易读反。

## 四、对企业外汇管理

结论与 v1 完全一致，三个默认动作全部保持：即期→当日结汇，套保→足额锁，工具→远期。

新增一条可以写进制度的观察：

> **中间价不能当作当日行情的方向指引。** v2 实测显示即期系统性地比中间价弱，把中间价的日间变化读成"央行看多/看空人民币"，在方向上大概率是错的。

唯一还值得投的数据方向：**境内即期的开盘价与日内序列**。它是把 `rF` 那个观察变成可验证结论的唯一途径，也是"当日结汇的日内择时"这个真实企业问题的唯一入口。这需要一次全新的预注册和一段新的样本外。

## 五、样本外用尽

按 v2 预注册第 1 节和第 8 节：**2025-01 ~ 2026-08 这段样本外已经用掉两次，就此封存。** 之后任何新想法只能向前纸面跟踪，等新数据积累够了再检验。

这条现在生效，不因为 v2 出现了一个"差点就通过"的结果而放宽。
