# 事件驱动 USD/CNY 研究：预注册规则

## 0. 这份文件是干什么的

这份文件在**看到任何收益结果之前**写完并提交。它把标的、事件类目、方向规则、时间窗口、样本划分和验收标准全部钉死。

之后所有的回测结果都必须在这份规则不变的前提下产生。规则要改，就新开一份 v2 并说明改动理由，旧结果一并作废。

**唯一的可审计防线是 git 历史：这份规则的 commit 必须早于任何结果文件的 commit。**

原因很直接：外汇上"先看行情、再挑新闻解释"太容易了。同一天美元涨，可以说是"联储偏鹰"，也可以说是"避险情绪"；美元跌，可以说是"降息预期"，也可以说是"风险偏好回升"。事后叙事的命中率是 100%，信息量是 0。

## 1. 要回答的问题

> 一条已经公开的宏观新闻，在**发布之后**，对 USD/CNY 的下一段走势，是否还有超出随机的方向信息？

这是一个**弱预测**问题，不是一个"预测汇率"的问题。及格线不是高准确率，是"稳定地略好于抛硬币，且样本外不消失"。

### 不回答的问题

- 不预测汇率点位。
- 不做汇率投机方向的建议。
- 不解释历史（"2022 年 4 月为什么涨 4.24%"这类问题一律不回答，它没有可证伪性）。
- 不评价新闻本身对错。

## 2. 标的与权威数据源

单一权威源：**FRED / 美联储 H.10**。不混用其他汇率源，避免口径和 revision 差异。

| 序列 | FRED ID | 含义 | 方向约定 |
| --- | --- | --- | --- |
| 主标的 | `DEXCHUS` | 人民币兑 1 美元（在岸，纽约口径） | 数值上升 = 人民币走弱 = USD/CNY 上行 |
| 对照标的 | `DEXJPUS` | 日元兑 1 美元 | 数值上升 = 日元走弱 |
| 美元强弱 | `DTWEXBGS` | 美联储广义美元指数 | 上升 = 美元走强 |
| 美债短端 | `DGS2` | 2 年期美债收益率 | 上升 = 美国利率预期上行 |
| 美债长端 | `DGS10` | 10 年期美债收益率 | 备中美利差用 |
| 风险偏好 | `VIXCLS` | VIX | 上升 = 避险 |

收益一律用对数收益：`r = ln(P_t / P_{t-1})`。

### 已知缺口（本阶段不补，但必须在报告里明说）

- **无 CNH**（离岸人民币）。FRED 没有。CNH-CNY 价差是判断结售汇压力方向的关键变量，缺它会削弱识别能力。
- **无中国国债收益率日频**。中美利差只能等价用 `DGS10` 单边变动近似，这是个明确的简化。
- **无日内数据**。见第 7 节。
- **无中间价**。人民币中间价相对模型的偏离（逆周期因子）是境内定价的核心，本阶段完全缺失。

## 3. 时间口径与事件日归属（冻结，v1.1 修订）

### v1.1 对 v1.0 的两处修订

两处都在**任何收益结果产生之前**，理由记录在下面，不允许事后再改。

**修订一：发现导出时间不是北京时间。** 微信导出脚本用 `datetime.fromtimestamp()` 取本机本地时间，而本机时区是 `Eastern Standard Time`，固定 UTC-5 且**已关闭夏令时**。因此 CSV 的 `time` 列是 UTC-5，北京时间 = 该值 **+13 小时**（固定偏移，无 DST 分支）。

三重独立验证：

- 首条消息 `2019-06-27 18:47` 正文写"周四纽约尾盘"。按 UTC-5 解释即纽约当日 19:47（EDT），在周四收盘之后，成立；按北京时间解释则是纽约周四 06:47，尚未收盘，不成立。
- 1184 条早报中 944 条标题自带日期（"2023.4.27早报""【26年8月24日早报】"）。用 +13 小时换算出的北京日期与标题日期比对，**941 条一致、仅 3 条不符**。
- 换算后北京时间的小时分布集中在 07:00–10:00（1463 条），符合早报形态；不换算则集中在 18:00–21:00，与"早报"矛盾。

未修正前，每一个事件都会被系统性错置 13 小时，跨日错置会让事件日整体偏移一天。**任何用到时间的代码必须经 `events/wechat_time.py` 换算，禁止直接使用 CSV 原值。**

**修订二：事件时间改用群消息送达时间，不再要求新闻原始发布时间。** v1.0 写的理由是"转发时间会制造虚假的新闻领先行情"——**这个方向判断是错的**。转发时间严格**晚于**原始发布时间，用它测量的反应窗口在原始行情反应**之后**，只会低估信号，不可能凭空造出前视偏差。

改用送达时间的三条理由：

1. 早报内部的单条新闻不带时间戳，按 v1.0 规则要丢弃几乎全部样本，研究无法进行。
2. 送达时间是**信息对企业实际可得的时间**，这正是要回答的问题——财务人员早上读到这份早报，按机械规则行事，有没有用。
3. 早报送达北京时间 07:00–10:00，集中在 08:00（950 条），**早于境内即期市场 09:30 开盘**，当日确实可执行。

正文里明确写出发布时间的条目（少数），仍以正文时间为准。

### 归属规则（不变）

2. **事件日按纽约时间归属。** `DEXCHUS` 是纽约中午买入价（NY noon buying rate），北京时间约为次日 00:00。归属规则：

2. **事件日按纽约时间归属。** `DEXCHUS` 是纽约中午买入价（NY noon buying rate），北京时间约为次日 00:00。归属规则：

   ```
   把新闻发布时间转换为 America/New_York 本地时间
   若该时刻 <= 当日 12:00  → 事件日 D = 该纽约日期
   若该时刻 >  当日 12:00  → 事件日 D = 下一个纽约日期
   再把 D 前滚到 DEXCHUS 序列中实际有报价的最近一天（跳过节假日）
   ```

   早报送达北京 D 日 08:45 -> 纽约 D-1 日 19:45，晚于 D-1 中午 -> 事件日 = D，当日境内开盘后可执行，口径自洽。

   直觉检查：北京时间 D 日 09:00 的新闻 = 纽约 D-1 日 21:00 → 事件日 D-1？**不对**，需要注意跨日：北京 D 09:00 对应纽约 D-1 21:00，晚于 D-1 的中午，因此事件日 = D。北京 D 日 20:30（美国数据常见发布时间）对应纽约 D 08:30，早于 D 中午，事件日 = D。两者归到同一天，符合直觉。

3. **跨时区一律显式带时区**，不允许用裸 naive datetime 做比较。

## 4. 事件类目（封闭列表）

只有这 6 类。不在列表里的新闻标记为 `other` 并**排除出统计**，不允许临时增补类目来救结果。

| 代码 | 类目 | 典型触发内容 |
| --- | --- | --- |
| `US_MON` | 美国货币政策 | FOMC 决议、点阵图、联储官员讲话、纪要 |
| `US_DATA` | 美国经济数据 | CPI、非农、PCE、零售、PMI、GDP |
| `CN_POL` | 中国政策 | 降准降息、MLF/LPR、财政刺激、地产政策、政治局会议 |
| `CN_DATA` | 中国经济数据 | 中国 CPI/PPI、社融、进出口、GDP、PMI |
| `TRADE` | 中美贸易与地缘 | 关税、出口管制、实体清单、元首会晤、地缘冲突 |
| `FX_POL` | 汇率政策直接干预 | 逆周期因子、外汇存款准备金率、离岸央票、口头指导 |

分类由**规则表 + 人工抽检**产生，不用 LLM 批量分类。先手工标注 100 条建立基线；只有在基线证明信息量存在之后，才考虑上模型。

理由：现有宽关键词分类的方向命中率是 43%–53%，等于没有信息。在没有信息的标注上叠加模型，只会把噪声包装得更精致。

## 5. "意外"的定义（冻结）

新闻本身不带方向信息——发布即已被定价。有信息的是**相对预期的偏离**。我们没有 consensus 预测数据，因此用**因果分段**的市场反应作为意外的代理：

```
意外代理（在事件日 D 测量）：
  Δ2Y   = DGS2[D] - DGS2[D-1]        美国利率预期的变动
  ΔDXY  = ln(DTWEXBGS[D] / DTWEXBGS[D-1])   美元强弱的变动

响应（在 D+1 测量）：
  r1 = ln(DEXCHUS[D+1] / DEXCHUS[D])
```

**硬约束：意外和响应不允许在同一段时间内测量。** 用 D 日的美元变动去解释 D 日的 USD/CNY 变动是循环论证——它们本来就是同一个美元行情的两个投影，相关性高不代表有预测力。

因此主判据固定为 **r1**，它在事件日收盘后完全可交易。`r0` 只作为"市场确实有反应"的确认，**不进主判据**。

阈值（冻结）：`|Δ2Y| >= 3bp` 或 `|ΔDXY| >= 0.20%` 才算"产生了意外"，否则标记为 `no_surprise` 并排除。

### 已识别但本阶段不启用：正文自带的市场预期（记录在案）

早报的"今日重点关注"小节直接给出待发布数据的**预估值和前值**（如"美国第一季度GDP价格指数环比初值（预估为3.7%，前值为3.9%）"，全样本 238 条含 `预估`/`前值`）。配合次日早报里公布的实际值，可以构造**真正的 consensus surprise**，而不是本阶段使用的市场反应代理。

这条线**本阶段不启用**，理由是它会把 PR#3 的抽取复杂度抬高一个量级，且跨日配对本身就是一个需要单独验证的环节。记录在此是为了防止将来把它当成"新想法"重新发明，也为了说明本阶段的意外代理是有已知上位替代的。

### 缺观测的处理（冻结）

事件日或窗口端点上任一所需序列缺观测时，**该事件整条剔除，不做前值填补、不做插值**。

理由：填补会在"数据缺失"和"市场无变动"之间制造假的零变动，而零变动恰好落在 `no_surprise` 的判定边界上，会系统性地污染样本。

实测缺口（以 DEXCHUS 报价日历为主日历，研究窗口 2019-06-27 起共 1788 个报价日）：
`DGS2` 缺 4 天、`DTWEXBGS` 缺 1 天、`VIXCLS` 缺 7 天、`DEXJPUS` 缺 0 天。按最坏情况全部剔除，损失不超过 12 天，可以接受。

## 5b. 第二个测量目标：波动（冻结）

方向和波动是两个目标，难度差一个量级，必须分开预注册。

| 目标 | 度量 | 用途 |
| --- | --- | --- |
| 方向 | `r1` 的符号 | 即期结汇择时、套保比例 |
| **波动** | `|r1|`、`|r5|` | **远期 vs 期权的工具选择** |

公开的事件研究里有一条稳定的经验：**围绕已排期的重大事件，绝对波动幅度显著抬升，但方向依然不可预测。** 如果这批数据也是这样，那么本项目最有把握的产出不是"预测涨跌"，而是"预测未来这几天会不会颠"——而后者恰好是期权定价的核心输入。

波动目标的验收标准（冻结）：

1. 样本外事件日次日 `|r1|` 的中位数 / 非事件日 `|r1|` 的中位数 `>= 1.20`
2. Mann-Whitney U 双样本检验 `p <= 0.10`
3. 训练期与样本外的比值之差不超过 0.15
4. 安慰剂：随机日期的比值 >= 真实比值的比例 `<= 10%`

**方向目标和波动目标独立结算。** 方向不过、波动过，结论是"这套信号只能用于工具选择，不能用于择时"，这仍然是有价值的结论，不算失败。反之亦然。

## 6. 方向规则表（冻结）

规则是**机械的**，输入只有类目和两个意外代理的符号。没有自由裁量项。

| 条件 | USD/CNY 方向偏置 |
| --- | --- |
| `US_MON` / `US_DATA` 且 Δ2Y > 0 且 ΔDXY > 0 | 上行（人民币走弱） |
| `US_MON` / `US_DATA` 且 Δ2Y < 0 且 ΔDXY < 0 | 下行 |
| `CN_POL` / `CN_DATA` 且 ΔDXY < 0 | 下行 |
| `CN_POL` / `CN_DATA` 且 ΔDXY > 0 | 上行 |
| `TRADE` 且 ΔDXY > 0 且 VIX 上行 | 上行 |
| `TRADE` 且 ΔDXY < 0 且 VIX 下行 | 下行 |
| `FX_POL` | 逆当前 20 日趋势方向（政策目标是抑制单边预期） |
| **两个意外代理符号冲突** | **无方向，不进统计** |

第 8 行是这套规则最重要的一条：**信号冲突时不强行给方向**。事后叙事之所以百发百中，就是因为它从不承认"这天说不清"。

明确禁止的做法：把"地产刺激""关税""政治表态"这类词直接映射成固定方向。同一个词在不同的增长预期、利差、风险溢价和资金流背景下方向相反。方向只能由上表的机械条件产生。

## 7. 窗口与重叠处理（冻结，v1.1 扩充）

### 为什么不能只看当日和次日

一次加息在公布当天可能毫无反应——市场早已定价。但利差一旦拉开，资金流、结售汇意愿、远期点差会在**数周到数月**里逐步体现。只测 `r1` 会系统性地漏掉这条最重要的传导链。

问题在于：长窗口在统计上极不可靠。7 年数据里，60 交易日的窗口只能切出约 28 个互不重叠的观测；用重叠窗口做显著性检验会把有效样本量虚增一个量级，得出的 p 值是假的。

所以**短窗和长窗用两套完全不同的方法**，并且**长窗不作为独立验收项**。

### 短窗：事件研究（统计可靠，用于择时）

| 窗口 | 定义 | 角色 |
| --- | --- | --- |
| `r0` | `ln(P[D]/P[D-1])` | 反应确认，不进主判据（含部分同期信息） |
| `r1` | `ln(P[D+1]/P[D])` | **方向主判据**，事件日后完全可交易 |
| `r5` | `ln(P[D+5]/P[D])` | 持续性；即期结汇递延窗口的上限也是 5 日 |

日内窗口（30 分钟 / 1 小时）不做：FRED 是日频单点，强行近似是伪精度。报告里一律标"未测"。

### 长窗：状态变量（对应企业真实持有期）

长期影响**不用事件窗口测，用状态变量测**。事件是离散的点，利差是连续的状态；把"加息"当成一个点去看 60 天后的收益，丢掉了这 60 天里利差究竟走阔还是收窄的全部信息。

定义两个状态变量（冻结）：

```
CUM_2Y[t]   = DGS2[t] - DGS2[t-60]           过去 60 交易日美国短端利率的累积变化
CUM_EVT[t]  = 过去 60 交易日内 上行事件数 - 下行事件数    （按第 6 节规则表判定）
```

检验对象：`CUM_2Y[t]` / `CUM_EVT[t]` 对未来 20 日和 60 日收益 `r20`、`r60` 的方向解释力。

三条纪律：

1. **只用非重叠样本做显著性检验。** `r60` 每 60 个交易日取一个观测，`r20` 每 20 个取一个。有效样本量必须在报告里明写（预计 `r60` 约 28 个、`r20` 约 85 个），不允许用重叠样本报 p 值。
2. **长窗不作为独立验收项。** 它只回答"方向是否与短窗一致"。
3. **若短窗无效而长窗"有效"，优先判定为过拟合，不判定为发现。** 28 个观测上任何看起来漂亮的结果都更可能是噪声——这条必须先写死，否则事后一定会想反过来解释。

### 已知缺口：中美利差只有美国一侧

真正驱动资金流的是**利差**，不是美国单边利率。中国国债日频收益率不在 FRED 上，本阶段 `CUM_2Y` 只是利差的单边代理。

补齐路径（记录在案，本阶段不做）：本机已有 Tushare 权限，其宏观接口可取中国国债收益率日频序列。补齐后 `CUM_SPREAD = (US2Y - CN10Y)` 才是完整口径。在补齐之前，所有涉及利差的结论都必须标注"单边代理"。

### 重叠处理

- 同一事件日出现多条同类目事件：**合并为一个事件**，方向取该日规则输出（规则输入是当日的市场变量，本来就唯一）。
- 同一事件日出现多个不同类目：若方向一致则保留，方向冲突则整日剔除。
- `r5` 窗口重叠导致的样本自相关：方向的显著性检验只用 `r1`（不重叠），`r5` 仅作描述性展示，不做显著性声明。

## 8. 样本划分与对照（冻结，v1.2 修订）

### 抽取后暴露出的问题：新闻不是稀缺事件

PR#3 抽完之后发现：研究窗口 1787 个报价日里，**1430 天（80.0%）有宏观新闻条目**；即使过了"意外"阈值（`|Δ2Y| >= 3bp` 或 `|ΔDXY| >= 0.2%`），仍有 1012 天（56.6%）。

这直接废掉了 v1.0 设计的安慰剂检验：**当 80% 的日子都是"事件日"时，随机抽的"非事件日"和事件日几乎是同一批样本，检验没有任何区分力。**

同时暴露第二个问题：单日出现 ≥2 个类目的有 957 天（占 66.9%），"方向冲突整日剔除"会剔掉大量样本，且剔除本身可能与行情相关。

### 修订后的对照设计

| 检验 | 零假设 | 做法 |
| --- | --- | --- |
| **主检验** | 规则给出的方向不含信息 | 有向命中率 vs 50%，单侧精确二项检验 |
| **安慰剂（改）** | 方向标签可随意互换 | **在事件日之间随机重排方向标签 1000 次**，不是随机挑日子。保留日历聚集和波动聚集，只打乱标签 |
| **增量检验（新增，最关键）** | 新闻没有增量，起作用的只是美元动量 | 同一套市场变量规则在**全部报价日**上跑一遍（去掉新闻条件），比较两者命中率 |

### 增量检验为什么是最关键的一条

必须诚实承认第 6 节规则表的结构：它的方向输入是 `Δ2Y`、`ΔDXY`、`VIX`——**全是市场变量，新闻只决定"用哪一行规则"**。这意味着这套东西很可能只是"美元指数涨了、明天人民币跟着贬"的动量策略披了一层新闻外衣。

所以：

> **事件条件下的命中率必须显著高于同一套市场变量规则在全部报价日上的命中率。两者无显著差异时，结论是"新闻无增量价值，起作用的是美元动量"，登记为负结果。**

这正是本项目最初要回答的问题——不是"新闻能不能解释行情"，而是"新闻相对于已经能看到的市场变量，还有没有多余的信息"。

### 增量检验的基线定义（冻结，跑之前钉死）

"去掉新闻条件"必须有唯一定义，否则事后可以挑一个对自己有利的基线。声明两个，**两个都报告**：

| 基线 | 定义（对**每一个报价日**，不看有没有新闻） | 对应的直觉 |
| --- | --- | --- |
| `B1` 同号规则 | `Δ2Y` 与 `ΔDXY` 同号则方向取该符号，异号则无方向 | 美债+美元双确认的动量 |
| `B2` 纯美元规则 | 方向 = `ΔDXY` 的符号 | 纯美元动量 |

事件条件规则必须**同时**跑赢 `B1` 和 `B2` 才算通过增量检验。只赢一个，结论是"新闻的增量不稳健"。

### 随机种子（冻结）

安慰剂重排使用固定种子 `20260830`，重复 1000 次。种子写死在代码里，不允许换种子重跑。

### 事件强度分层（两档，全部预先声明）

| 档 | 阈值 | 天数 | 占报价日 |
| --- | --- | --- | --- |
| 主档 | `\|Δ2Y\| >= 3bp` 或 `\|ΔDXY\| >= 0.2%` | 1012 | 56.6% |
| 严档 | `\|Δ2Y\| >= 10bp` 或 `\|ΔDXY\| >= 0.5%` | 255 | 14.3% |

**两档都在看结果之前声明，两档结果都必须报告。** 因为报告两个切分等于做了两次检验，主判据的显著性门槛相应收紧到 `p <= 0.05`（原 0.10）。不允许只报好看的那一档。

## 9. 验收标准（冻结，v1.2 修订）

样本外必须**同时**满足以下五条，才允许说"有信息价值"：

1. 样本外有效事件数 `n >= 30`
2. 样本外 `r1` 方向命中率的单侧精确二项检验 `p <= 0.05`（因声明了两档强度，门槛由 0.10 收紧）
3. 样本外命中率 >= 训练期命中率 - 5 个百分点（不能出现断崖式衰减）
4. 方向标签重排安慰剂中，重排后命中率 >= 真实命中率的比例 `<= 10%`
5. **增量检验通过**：事件条件命中率显著高于全报价日的市场变量基准（差值的双样本检验 `p <= 0.10`）

**任何一条不满足，结论就是"无信息价值"，写成负结果登记，不再调参重跑。**

波动目标（第 5b 节）独立结算，四条标准见该节。

## 10. 如果通过，怎么用到企业外汇管理

企业的外汇需求不止一种，不同需求接的是不同的测量目标，不能一张表打天下。

### 三类决策，三个不同的接入点

| 企业决策 | 具体问题 | 接哪个目标 | 默认动作（信号失效时的落点） |
| --- | --- | --- | --- |
| **即期结汇/购汇择时** | 今天到账的这笔美元，今天换还是等几天 | 方向 `r1`/`r5` | 立即结汇 |
| **套保比例** | 三个月后的应收，锁多少 | 方向 | 按目标比例足额锁 |
| **工具选择：远期 vs 期权** | 锁死汇率，还是付权利金留住上行 | **波动** `\|r1\|` | 远期（成本确定、可审计） |

### 即期结汇择时（用户明确提出的需求）

即期结汇和远期套保的性质不同：**这笔钱迟早要换，决策不是"做不做"，而是"什么时候做"。** 因此用弱信号做择时并不等于投机——不动作本身也是一个头寸。

规则（冻结）：

- 默认动作是**当日结汇**。
- 只有在信号方向有利（结汇方看 USD/CNY 上行）且模型质量达标时，才允许**递延**。
- 递延**最长 5 个交易日**，到期无条件执行，不允许滚动展期。
- 递延比例上限 50%，另一半照常当日结汇。
- 任何时候出现方向不利信号，立即执行剩余部分。

三条硬约束的作用：递延有上限（不会演变成裸多头）、有强制到期（不会"套牢了就一直等"）、有分批（不会全押在一次判断上）。**这三条比信号本身重要**——它们保证了即使信号完全无效，损失也被限制在 5 个交易日的汇率波动内，而不是无限期的敞口。

### 工具选择：远期还是期权

这是方向信号帮不上忙、但波动信号真正能用的地方。

- 远期：锁死汇率，零权利金，放弃有利方向的全部上行。
- 期权：付权利金，保住下行，留住上行。权利金随**隐含波动率**上升而变贵。

决策逻辑：

| 未来窗口内的事件密度 | 波动信号 | 建议 |
| --- | --- | --- |
| 有重大排期事件（FOMC/CPI/关税节点） | 预期 `\|r\|` 抬升 | 期权的保护更值钱，但权利金也更贵——关键是看**市场是否已经把这个波动定价进去**；若隐含波动率尚未抬升，期权相对便宜 |
| 无重大事件 | 预期 `\|r\|` 正常 | 远期，不付无谓的权利金 |

**必须承认的局限：** 本项目没有期权隐含波动率数据，因此**只能给出"预期实际波动"的一侧，无法判断它相对权利金是贵还是便宜**。没有这一半，工具选择建议是不完整的。诚实的定位是：本项目输出"未来 N 日预期波动是否高于常态"这个输入，权利金是否划算需要银行报价方能判断。把这条缺口写在这里，是为了防止把半个结论当成完整建议卖出去。

### 为什么弱信号在这里仍然有价值

企业侧的损失函数是**歪的**：

- 该锁没锁、汇率反向走 → 真金白银的经营亏损，要向老板解释。
- 锁了但其实有利 → 少赚，在预算内、可解释、能过审计。

两边代价不对称，所以对**保护性动作**（足额锁、当日结汇、买远期）默认执行，只对**放弃保护的动作**（少锁、递延、改期权）要求信号达标。这就是"只降不升"在三类决策上的统一表述：

> **信号只能用来减少保护，不能用来增加敞口。** 任何情况下都不允许基于信号建立与真实业务无对应关系的头寸。

真实收益来自三处，都不是"猜得准"：

1. **省下的成本**：递延结汇省下的价差、少锁部分省下的远期点差和保证金占用、无事件期不买期权省下的权利金。
2. **决策留痕**：每次调整都有可回溯的规则依据，而不是"我觉得美元要涨"。财务和审计能接受的是前者。
3. **拒绝的能力**：模型报 `reject` 时系统自动落回默认保护动作，这本身就拦掉一次基于叙事的裸敞口决策。
